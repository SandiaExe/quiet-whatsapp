# Quiet WhatsApp: textos para la Chrome Web Store

Copiar cada bloque en el campo indicado del panel de desarrollador.

## Descripción (English, idioma por defecto)

```
————————————————————————————————————————————————————————————————————————————
Quiet WhatsApp makes WhatsApp Web calmer and more private: hide what you don't use, blur what others shouldn't see and give it your own colors.
————————————————————————————————————————————————————————————————————————————
  NEW IN 1.1

  • Status rings around profile photos are now fully hidden.
  • The unread dot on the Chats button is gone when badges are hidden.
  • The Meta AI shortcut on the start screen is removed completely.

————————————————————————————————————————————————————————————————————————————
  HIDE

  • Calls, Status, Channels, Communities and Meta AI, tooltips and shortcuts included.
  • Notification badges in the sidebar, the tab title and the icon.

————————————————————————————————————————————————————————————————————————————
  BLUR

  • Messages, time and date, photos and videos, names, profile photos and chat previews.
  • Each one on its own, with adjustable intensity.
  • Reveal on hover: only the element under the cursor is shown.
  • Blurred before it is drawn: nothing flashes while you stream or share your screen.

————————————————————————————————————————————————————————————————————————————
  THEMES & LANGUAGES

  • 10 color themes, including a light one (Snow), tuned so every text stays readable.
  • English, Spanish, French, Portuguese, German, Italian, Polish and Russian.

————————————————————————————————————————————————————————————————————————————
  SETUP

  Open WhatsApp Web, click the Quiet WhatsApp icon and choose what to hide, blur or recolor. Done!

————————————————————————————————————————————————————————————————————————————
  It never reads, stores or sends your messages: it only changes how the page looks [ no tracking, no data collected ;) ]

  Not affiliated with or endorsed by WhatsApp or Meta.
```

## Pestaña "Privacy practices"

**Single purpose (propósito único)**
Customize the WhatsApp Web interface: hide unused sections, blur private content and apply color themes.

**Permission justification: storage**
Saves the user's settings (which sections are hidden, which content is blurred, blur intensity and the selected theme) so they persist and sync across the user's Chrome browsers.

**Host permission justification: content script on https://web.whatsapp.com/***
The extension only works on WhatsApp Web. Its content script and stylesheet hide interface elements, blur content and apply theme colors on that page. It does not read message content to send or store it anywhere.

**Remote code**
No, I am not using remote code. All code is included in the package.

**Data usage**
Marcar que NO se recoge ninguna categoría de datos de usuario. Marcar las tres certificaciones:
- I do not sell or transfer user data to third parties, outside of the approved use cases
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- I do not use or transfer user data to determine creditworthiness or for lending purposes
